# Playable Tennis — 0.2.2 development snapshot

B42.20+용 플레이어 1대1 테니스와 자유 벽치기 모드입니다. 움직이는 AI 상대는 없으며, 혼자 규칙을 확인하는 고정 리턴점 테스트 모드가 있습니다. 모드 ID는 PlayableTennis입니다. 사용자 테스트에서 빈 벽의 솔로 랠리는 확인됐지만, 최신 모션·표시 수정과 2인 접속·아이템 전환 동기화는 실기 검증 전입니다. **버전은 테스트 중인 0.2.2로 유지하며, 정식 릴리스로 확정하지 않았습니다.**

공개 소스: [ppebble/playable-tennis](https://github.com/ppebble/playable-tennis) · [좀보이드 모드 카탈로그](https://github.com/ppebble/project-zomboid-modding)

## 라켓 전환

인벤토리의 라켓 우클릭 → **스포츠용으로 전환 / 무기용으로 전환**합니다.

| 아이템 | 용도 |
|---|---|
| 기존 테니스 라켓 (Base.TennisRacket) | 원래 무기. 테니스·벽치기 사용 불가 |
| 테니스 라켓 (스포츠용) (PlayableTennis.SportsTennisRacket) | 스포츠 전용. 코트 밖에서도 일반 공격 불가 |

같은 기본 라켓 아이콘·모델·무게를 사용합니다. 전환은 B42 기본 timed-action의 서버 완료 절차로 수행합니다. 내구도·최대 내구도·수리 횟수·즐겨찾기·사용자 이름/무게·modData·혈흔과 들고 있던 손을 보존합니다. 복제나 내구도 초기화가 아닙니다.

라켓은 캐릭터 기본 인벤토리에 있어야 합니다. 배낭에서 꺼내고, 단축 슬롯에 부착했다면 먼저 해제하세요. 사망·차량 탑승 중에는 전환하지 않습니다. 스포츠용을 들면 참가 여부와 상관없이 일반 공격을 차단합니다. 무기용 전환 후 마우스 양 버튼을 놓으면 이전 공격 허용 상태로 복구합니다.

## 자유 벽치기 — 코트 등록 불필요

1. **오른손 스포츠용 라켓 + 왼손 테니스공**을 장비합니다. 게임 기준 주 손 / 보조 손입니다. 인벤토리에 공이 있는 것만으로는 부족합니다.
2. 벽에서 **수직 깊이 1–14타일** 떨어져 서서 **우클릭을 누른 채 벽을 겨냥 → 좌클릭**합니다. 월드 우클릭 메뉴의 Start wall practice here도 가능합니다.
3. 동·서·남·북 어느 면이든, 1타일 벽부터 사용할 수 있습니다. 문·창문·울타리는 제외하고 벽까지의 바닥과 경로가 로드되어 있고 비어 있어야 합니다.
4. 시작 후 우클릭을 놓고, 커서 조준 + 좌클릭으로 리턴합니다. 다시 시작할 때도 보조 손에 공이 필요합니다. 리턴에는 보조 손 공이 필수는 아닙니다.
5. Leave court로 종료합니다. 최고 연속 기록은 플레이어별로 저장하며 공·진행 세션은 저장하지 않습니다.

연습 공간의 깊이는 시작 위치와 관계없이 벽에서 14칸입니다. 시작 거리는 벽에 수직인 깊이 1–14칸이며 대각선 직선거리로 제한하지 않습니다. 뒤쪽으로 갈수록 좌우 타격 영역이 넓어져 깊이 14칸에서는 양쪽 각각 4칸 더 넓습니다. 벽의 반사 구간은 바뀌지 않습니다. 벽 반사는 기존 속도를 유지하고 벽 방향 속도만 반전합니다. 착지 거리 보정은 제거했으며, 14칸은 플레이 영역의 깊이입니다. 코트 등록이나 사각형 선은 필요하지 않습니다. 실제 벽 구간 안으로 조준이 제한됩니다. 공 경로에 새 장애물이나 로드되지 않은 바닥이 나타나면 랠리가 멈춥니다. 벽이 철거되거나 멀리 이탈하면 종료합니다. 천장·3D 물체 높이까지 모두 계산하는 실내 스쿼시 시뮬레이션은 아닙니다.

## 1대1 테니스

1. 월드 우클릭 → Playable Tennis → Draw / replace court를 선택합니다. 첫 모서리와 반대 모서리를 클릭하면 목장 지정과 같은 사각형 미리보기로 선택합니다. 너비(X) 6–14타일, 길이(Y) 12–30타일이며 잘못된 크기는 빨간색입니다. 우클릭/Escape로 취소합니다.
2. 서버가 새 범위를 검증하면 기존 등록 코트와 그 경기를 종료하고 새 코트 하나로 교체합니다. 잘못된 범위는 기존 코트를 지우지 않습니다. 별도 물리 네트는 필요하지 않습니다.
3. Refresh court list 후 메뉴를 다시 열고 두 사람이 같은 코트의 Join을 선택합니다.
4. **두 사람이 모두 참가해야 테니스 입력이 활성화됩니다.** 먼저 온 사람은 북쪽 1번, 다음은 남쪽 2번입니다. 상대 대기 중에는 J/K와 마우스 모두 서브·스윙을 보내지 않습니다.
5. 서브하는 사람은 주 손 스포츠용 라켓 + 보조 손 테니스공이 필요합니다. 받는 사람도 스포츠용 라켓이 필요합니다.

0–15–30–40, 듀스·어드밴티지, 대각선 서비스 박스, 서브 첫 바운드, 더블폴트, 네트·아웃·두 번 바운드를 처리합니다. 기본은 먼저 2게임 승리, 게임마다 서버 교대입니다. 세트·타이브레이크·코트 교대는 없으며 네트 서브는 렛 대신 폴트입니다. 서브할 베이스라인 반쪽은 HUD로 확인합니다.

스포츠용 라켓은 상대 대기 중에도 무기가 아닙니다. 좀비와 싸우려면 무기용 라켓이나 다른 무기로 교체하세요. 이 모드는 무적/안전지대를 만들지 않습니다. 상대 이탈·접속 종료·사망 시 경기 세션을 종료합니다.

## 혼자 하는 1대1 규칙 테스트

코트를 그린 뒤 스포츠용 라켓과 공을 들고 우클릭 → Playable Tennis → **Solo test: fixed return target**을 선택합니다. 북쪽 1번 자리를 사용하며 상대편 중앙보다 왼쪽의 노란 원이 고정 리턴 범위입니다. 그 범위에서 정상 타격 높이에 도달한 공만 자동 리턴하며, 이동하거나 공을 쫓지는 않습니다. 서비스 공은 정상 첫 바운드 판정을 통과해야 합니다.

준비 상태에서 **Test: send a ball from opponent side**를 선택하면 상대 서브를 보낼 수 있습니다. 자신의 차례 대신 상대 서브로 시작하는 테스트 전용 기능입니다. 랠리 도중 공을 교체하지 않습니다. 직접 서브하거나 공을 받아 노란 원 쪽으로 되돌려 보냅니다. Leave court로 종료한 뒤 일반 Join을 사용하면 정상 2인 경기로 돌아갑니다. 이 기능은 규칙·조작감 검사이며 두 클라이언트의 네트워크 동기화 검증을 대체하지 않습니다.

## 조작 및 설정

| 조작 | 동작 |
|---|---|
| 마우스 이동 | 랠리 중 우클릭 없이 목표 조준; 초록 십자 표시 |
| 우클릭 유지 + 좌클릭 | 벽치기 시작/재시작 또는 1대1 서브 |
| 좌클릭 | 랠리 중 스윙; 이동·달리기는 평소 조작 그대로 |
| K / J | 세션 내 서브 / 스윙 보조키 |
| 방향키 + J/K | 보조키 조준 방향 |
| Leave court | 경기·벽 연습 종료 |

1대1 상대 대기 상태에서는 스포츠 입력이 비활성입니다. 채팅/텍스트 입력과 UI가 소비한 클릭으로는 스윙하지 않습니다. 타격 반경 기본 1.8타일, 높이 0.15–2.4, 헛스윙 포함 간격 0.25초입니다. 좌우 목표만 수동 조절하며 깊이·포물선은 보조 계산합니다. 파워·스핀은 없습니다.

샌드박스: Enabled=true, AllowCourtCreation=true(1대1 등록 권한만 제어), GamesToWin=2(1–6), BallSpeed=9(6–14), HitRadius=1.8(1–2.5). 물리 설정은 새 세션에 적용됩니다. 등록 테니스 코트는 월드에 하나이며, 새 유효 코트는 다른 소유자의 기존 코트도 교체합니다. 임시 벽치기는 영향을 받지 않으며 동시 스포츠 세션은 16개입니다. 빈 코트는 소유자/관리자가 Remove로 삭제합니다. 구버전 등록 벽 코트는 참가할 수 없으며 Remove로 지울 수 있습니다.

## 설치와 검증

Contents/mods/PlayableTennis 전체를 %USERPROFILE%/Zomboid/mods/PlayableTennis로 복사하고 활성화합니다. **서버와 모든 클라이언트에 동일한 개발 스냅샷 파일**이 필요합니다. 버전 번호를 유지하며 수정 중이므로 0.2.2 표기뿐 아니라 커밋/파일도 일치해야 합니다. 선택한 서버 프리셋 Mods에 PlayableTennis를 추가합니다. Workshop 미게시이며 기존 서버 프리셋·저장 게임을 자동 변경하지 않습니다.

scripts/test.ps1은 설치 게임의 Kahlua에서 실제 제작 Lua와 엔진 모형을 검사합니다. scripts/package.ps1 -Install은 기존 설치본 백업 후 복사·해시 대조합니다. 공은 가상 화면 표시이며 3D 가림은 없습니다. 약 1초의 바닐라 한손 스윙을 피해 없는 연출로 사용합니다. 이동을 막지 않고 이미 진행 중인 스윙을 재시작하지 않으며, 다른 행동이 진행 중이면 모션을 생략합니다. 타격 판정의 0.25초 간격과 모션 완료 시점은 별개입니다. 이미 진행 중인 공격 애니메이션이나 다른 모드의 직접 공격 호출을 취소하지 않습니다. 분할화면·지연 보정은 미지원입니다. 소스 검증과 실기 증거는 구분하며 실기 절차는 docs/PLAYTEST.md에 있습니다.
