# Playable Tennis — 0.2.2

B42.20+용 플레이어 1대1 테니스와 자유 벽치기 모드입니다. 모드 ID는 PlayableTennis입니다.

공개 소스: [ppebble/playable-tennis](https://github.com/ppebble/playable-tennis) · [좀보이드 모드 카탈로그](https://github.com/ppebble/project-zomboid-modding)

## 라켓 전환

인벤토리의 라켓 우클릭 → **스포츠용으로 전환 / 무기용으로 전환**합니다.

| 아이템 | 용도 |
|---|---|
| 기존 테니스 라켓 (Base.TennisRacket) | 원래 무기. 테니스·벽치기 사용 불가 |
| 테니스 라켓 (스포츠용) (PlayableTennis.SportsTennisRacket) | 스포츠 전용. 코트 밖에서도 일반 공격 불가 |

같은 기본 라켓 아이콘·모델·무게를 사용합니다. 전환은 B42 기본 timed-action의 서버 완료 절차로 수행합니다. 내구도·최대 내구도·수리 횟수·즐겨찾기·사용자 이름/무게·modData·혈흔과 들고 있던 손을 보존합니다. 복제나 내구도 초기화가 아닙니다.

라켓은 캐릭터 기본 인벤토리에 있어야 합니다. 배낭에서 꺼내고, 단축 슬롯에 부착했다면 먼저 해제하세요. 사망·차량 탑승 중에는 전환하지 않습니다. 스포츠용을 들면 참가 여부와 상관없이 일반 공격을 차단합니다. 무기용 전환 후 마우스 양 버튼을 놓으면 이전 공격 허용 상태로 복구합니다.

## 자유 벽치기 — 코트 등록 불필요

1. **오른손 스포츠용 라켓 + 왼손 테니스공**을 장비합니다. 게임 기준 주 손 / 보조 손입니다. 인벤토리에 공이 있는 것만으로는 부족합니다.
2. 벽에서 **수직 깊이 1–14타일** 떨어져 서서 **우클릭을 누른 채 벽을 겨냥 → 좌클릭**합니다. 월드 우클릭 메뉴의 Start wall practice here도 가능합니다.
3. 동·서·남·북 어느 면이든, 1타일 벽부터 사용할 수 있습니다. 문·창문·울타리는 제외하고 벽까지의 바닥과 경로가 로드되어 있고 비어 있어야 합니다.
4. 시작 후 우클릭을 놓고, 커서 조준 + 좌클릭으로 리턴합니다. 다시 시작할 때도 보조 손에 공이 필요합니다. 리턴에는 보조 손 공이 필수는 아닙니다.
5. 우클릭 → Playable Tennis → Remove wall practice area로 연습 영역을 삭제하고 종료합니다. 최고 연속 기록은 플레이어별로 저장하며 공·진행 세션은 저장하지 않습니다.

연습 공간의 깊이는 시작 위치와 관계없이 벽에서 14칸입니다. 시작 거리는 벽에 수직인 깊이 1–14칸이며 대각선 직선거리로 제한하지 않습니다. 뒤쪽으로 갈수록 좌우 타격 영역이 넓어져 깊이 14칸에서는 양쪽 각각 2칸 더 넓습니다. 선택하는 벽의 반사 구간은 최대 5칸, 뒤쪽 활동 폭은 최대 9칸입니다. 긴 벽도 겨냥한 지점 주변의 최대 5칸만 사용합니다. 벽 반사는 기존 속도를 유지하고 벽 방향 속도만 반전합니다. 착지 거리 보정은 제거했으며, 14칸은 플레이 영역의 깊이입니다. 코트 등록이나 사각형 선은 필요하지 않습니다. 실제 벽 구간 안으로 조준이 제한됩니다. 공 경로에 새 장애물이나 로드되지 않은 바닥이 나타나면 랠리가 멈춥니다. 벽이 철거되거나 멀리 이탈하면 종료합니다. 천장·3D 물체 높이까지 모두 계산하는 실내 스쿼시 시뮬레이션은 아닙니다.

## 1대1 테니스

1. 월드 우클릭 → Playable Tennis → Draw / replace my court를 선택합니다. 첫 모서리와 반대 모서리를 클릭하면 목장 지정과 같은 사각형 미리보기로 선택합니다. 짧은 변 8–10타일, 긴 변 18–20타일 (남북·동서 방향 모두 가능)이며 잘못된 크기는 빨간색입니다. 우클릭/Escape로 취소합니다.
2. 서버가 새 범위를 검증하면 기존 등록 코트와 그 경기를 종료하고 새 코트 하나로 교체합니다. 잘못된 범위는 기존 코트를 지우지 않습니다. 별도 물리 네트는 필요하지 않습니다. 중앙선과 방향이 일치하는 바닐라 테니스 네트는 허용하므로 기존 18×10 코트에서도 등록할 수 있습니다. 일반 울타리·벽·가구는 계속 차단합니다. 공은 실제 울타리에 튕기는 엔진 물체가 아니며, 가상 중앙 네트를 지날 때 높이 0.91 이하이면 네트 실패로 처리합니다.
3. Refresh court list 후 메뉴를 다시 열고 두 사람이 같은 코트의 Join을 선택합니다.
4. **두 사람이 모두 참가해야 테니스 입력이 활성화됩니다.** 먼저 온 사람은 북쪽(동서 코트에서는 서쪽) 1번, 다음은 반대편 2번입니다. 상대 대기 중에는 J/K와 마우스 모두 서브·스윙을 보내지 않습니다.
5. 서브하는 사람은 주 손 스포츠용 라켓 + 보조 손 테니스공이 필요합니다. 받는 사람도 스포츠용 라켓이 필요합니다.
6. 매 서브 전에 받는 사람이 대각선 반대편의 파란 **Receive Zone** 영역에 있어야 합니다. 서버가 현재 위치·층·생존·차량 탑승 여부·라켓 상태를 확인하고, 준비되지 않았으면 공을 발사하지 않습니다. 첫 폴트 이후 재서브에도 적용됩니다. 서브하는 사람은 녹색 **Serve Zone** 영역을 사용합니다.

0–15–30–40, 듀스·어드밴티지, 대각선 서비스 박스, 서브 첫 바운드, 더블폴트, 네트·아웃·두 번 바운드를 처리합니다. 40 이후 2점 차로 이기면 현재 대결이 끝납니다. 누적 게임/세트 승수는 기록하지 않으며 참가자가 직접 셉니다. 타이브레이크·코트 교대는 없으며 네트 서브는 렛 대신 폴트입니다. 서브 위치는 코트의 Serve Zone 표시로 확인합니다. 상단 중앙에는 필요한 경기 안내와 선수별 점수를 표시하며, 승리하면 승자의 이름과 Win을 표시합니다. 벽 연습은 Rally | Best | Depth만 표시합니다.

스포츠용 라켓은 상대 대기 중에도 무기가 아닙니다. 좀비와 싸우려면 무기용 라켓이나 다른 무기로 교체하세요. 이 모드는 무적/안전지대를 만들지 않습니다. 라켓을 놓거나 잠시 이동·접속 종료·사망하면 진행 중인 공을 취소하고 포인트 점수를 보존합니다. 같은 사용자 이름으로 돌아와 참가하면 이어서 진행합니다. 두 자리의 참가자는 유지되므로 다른 사람이 대신 들어갈 수 없습니다. 코트 삭제/교체, 참가자의 명시적인 Leave court, 현재 대결의 승리 때만 종료합니다. 서버 재시작 후에도 미완료 포인트 점수를 복원합니다.

## 조작 및 설정

| 조작 | 동작 |
|---|---|
| 마우스 이동 | 랠리 중 우클릭 없이 목표 조준; 초록 십자 표시 |
| 우클릭 유지 + 좌클릭 | 벽치기 시작/재시작 또는 1대1 서브 |
| 좌클릭 | 랠리 중 스윙; 이동·달리기는 평소 조작 그대로 |
| K / J | 세션 내 서브 / 스윙 보조키 |
| 방향키 + J/K | 보조키 조준 방향 |
| Leave court / Remove wall practice area | 경기 종료 / 임시 벽 연습 영역 삭제 |

1대1 상대 대기 상태에서는 스포츠 입력이 비활성입니다. 채팅/텍스트 입력과 UI가 소비한 클릭으로는 스윙하지 않습니다. 타격 반경 기본 1.8타일, 높이 0.15–2.4, 헛스윙 포함 간격 0.25초입니다. 좌우 목표만 수동 조절하며 깊이·포물선은 보조 계산합니다. 파워·스핀은 없습니다. 일반 리턴의 첫 바운드는 네트에서 상대 베이스라인까지 깊이의 45% 지점이며, 조준 십자가는 이 첫 착지점을 나타냅니다. 테니스 발사 궤적의 최고 높이는 2.4, 첫 바운드 뒤 최고 높이는 1.1로 제한합니다. 먼 샷은 수평 속도를 보정하고 바운드 이후에는 받을 시간을 확보하도록 감속합니다. 새 크기 제한은 새 코트 등록에만 적용하며 기존 큰 코트는 유지합니다. 벽치기의 기존 궤적은 유지합니다.

샌드박스: Enabled=true, AllowCourtCreation=true(1대1 등록 권한만 제어), BallSpeed=9(6–14), HitRadius=1.8(1–2.5). 물리 설정은 새 세션에 적용됩니다. 등록 테니스 코트는 사용자 이름(계정)당 하나씩 소유할 수 있습니다. 새 유효 코트는 본인 소유 코트만 교체하며 다른 소유자의 코트·점수는 보존합니다. 본인 코트는 겹쳐서 다시 그려 크기를 변경할 수 있으며, 같은 층의 다른 소유자 코트와 겹치는 생성만 거부합니다. 경계만 맞닿는 경우는 허용합니다. 임시 벽치기는 영향을 받지 않으며 동시 스포츠 세션은 16개입니다. 소유자/관리자가 Remove로 코트를 삭제하면 보존 중인 대결도 종료합니다. 구버전 등록 벽 코트는 참가할 수 없으며 Remove로 지울 수 있습니다.

## 플레이 경험치

테니스·벽 연습에서 성공한 서브/리턴 후 실제 랠리 시간을 기준으로 체력과 조준 시 발걸음 경험치를 줍니다. 기본은 활동 1분당 체력 20 XP, 조준 시 발걸음 3 XP를 바닐라 지급 함수에 전달합니다. 대기·일시정지·종료·헛스윙은 지급하지 않으며, 마지막 성공 타격에서 6초가 지나면 다음 성공 타격까지 중단합니다. 서버가 1초 단위로 지급하므로 입력 연타로 양을 늘릴 수 없습니다. 세션을 끝내면 1초 미만의 남은 활동 시간은 버립니다.

샌드박스의 **체력 경험치 배율**, **조준 시 발걸음 경험치 배율**은 각각 숫자 0–100, 기본 1입니다. 0은 해당 추가 경험치를 끄고, 0.5는 절반, 2는 두 배입니다. 적용 중인 샌드박스 값 변경은 다음 지급부터 반영합니다. 캐릭터 보너스·게임 경험치 설정·체력의 영양 제한은 바닐라 규칙을 따릅니다. 기본 무보너스 발걸음의 25% 보정에서는 3 XP 요청이 약 0.75 XP가 됩니다.

**운동 피로를 추가하지 않으며 지구력을 추가 차감하지 않습니다.** 달리기 등 원래 게임 동작의 지구력 소모는 그대로입니다. 정확한 레벨별 필요량과 Lifestyle 요가 비교는 docs/TRAINING.md에 기록했습니다.

## 설치와 검증

Contents/mods/PlayableTennis 전체를 %USERPROFILE%/Zomboid/mods/PlayableTennis로 복사하고 활성화합니다. **서버와 모든 클라이언트에 동일한 모드 파일**이 필요합니다. 선택한 서버 프리셋 Mods에 PlayableTennis를 추가합니다. 기존 서버 프리셋·저장 게임을 자동 변경하지 않습니다.

scripts/test.ps1은 설치 게임의 Kahlua에서 실제 제작 Lua와 엔진 모형을 검사합니다. scripts/package.ps1 -Install은 기존 설치본 백업 후 복사·해시 대조합니다. 공은 가상 화면 표시이며 3D 가림은 없습니다. 약 1초의 바닐라 한손 스윙을 피해 없는 연출로 사용합니다. 이동을 막지 않고 이미 진행 중인 스윙을 재시작하지 않으며, 다른 행동이 진행 중이면 모션을 생략합니다. 타격 판정의 0.25초 간격과 모션 완료 시점은 별개입니다. 이미 진행 중인 공격 애니메이션이나 다른 모드의 직접 공격 호출을 취소하지 않습니다. 공 표시는 서버 시각 기준 100ms 버퍼로 매 화면 프레임에 보간하며, 통신이 멈추면 마지막 위치에서 대기합니다. 입력 판정의 지연 보정과 분할화면은 미지원입니다. 소스 검증과 실기 증거는 구분하며 실기 절차는 docs/PLAYTEST.md에 있습니다.


배포 패키지는 Contents/mods/PlayableTennis만 포함합니다. tests/, docs/, scripts/와 빌드·백업 파일은 저장소의 개발 검증 자료이며 배포본에 포함되지 않습니다. 이전 버전의 솔로 테스트 경기 기록은 제거하고, 등록 코트와 일반 1대1 경기의 보존 점수는 유지합니다.
